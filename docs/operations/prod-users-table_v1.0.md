## 6. 보안 정책 (NFR-SEC-007 v1.5)

| 항목 | 정책 |
|---|---|
| PIN 형식 | 숫자 4자리 (`^[0-9]{4}$`) |
| BCrypt strength | 12 |
| 실패 잠금 | 5회 연속 실패 → 10분 자동 잠금 |
| PIN 강제 변경 주기 | 30일 (last_pin_change_at 기준 — V052) |
| Keycloak 연동 | Phase 5+ (사내 IT Pre-Phase 의존) — 현재 DaoAuth fallback |
